# What remains project-specific

The generic layer does not know these names and must not grow them.

- Task tracker and ticket lifecycle
- Risk tiers and the escalation ladder
- Product premerge / compile / clippy / cook gates
- Shared GPU locks and capture helpers
- Live visual proof / goldens
- Deploy / ship / push
- Worktree **creation** and merge/commit
- Native Codex / Claude / Grok rails and plugin runtimes
- Quota broker files (only a hook exists here)
- Extra fidelity read roots that belong to one machine layout
- Game-import / engine-agnostic product rules
- Coordinator / manager identity / stop-hook policy
- Project HANDOFF templates (lessons store, crate maps)
- Role taste (which vendor is “semantic” vs “wiring”)

A future project adapter is a **profile + maybe a thin alias**, not a
fork of this substrate.
